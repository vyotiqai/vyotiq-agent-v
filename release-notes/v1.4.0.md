Agent V 1.4.0 reworks Home and makes voice mode easier to talk to. Home now opens on the day and one sentence of what needs you, with the brief for your next task right under it. Voice mode answers faster, keeps to one voice at a time, and hears what you say while the agent is busy.

## Added

- **Home opens on the day and one sentence.** The weekday and one sentence of what Home already knows: what needs you, what failed, what is running, what is ready for review, the next scheduled run and any uncommitted files. Each fact opens its rows in place under the sentence. Your workspaces and the week open the same way from a quiet line at the foot, so everything Home showed before is still one click away.
- **Start your next task from Home.** The New task brief sits on Home under the day sentence. It is the same brief as in the task's pane, so text, checks, folders and attachments are shared between the two, and Start opens the task in its pane exactly as the pane's own Start does. A workspace row's New task points the brief at that workspace and puts the cursor in it.
- **A backdrop and a greeting for Home.** Settings, Appearance, Home: a backdrop band (none, pixels, field, or a picture you pick) and Your name for the greeting. A picture is copied into the app's own data folder and toned toward the page colour; the band hides under More contrast and forced colours.
- **The agent can set and read Home.** By voice or in a typed task, the agent can change Home's backdrop and greeting name, and read the day sentence as Home would draw it, without opening Home.
- **Voice questions you can type into.** When the agent asks something a yes or no can't answer, the task's own question form appears in the voice view and the mini window, so exact details can be typed rather than spelled out.
- **Voice can tell you about spend and other tasks.** Asked how things stand, the agent can now say this task's, today's and this month's spend, list the latest other tasks, and read another task.

## Improved

- **Spoken replies start sooner.** Spoken turns are meant to run with the model's thinking off, but on Claude Haiku 5.5 it never was, so it thought before every answer. Measured against the model directly, ten calls each, the first word came at about 1.3 seconds with thinking and 0.8 seconds without. Spoken turns now really turn thinking off on Claude Haiku 5.5 and Claude Sonnet 5.5, and turn it down to low on Gemini 3 and later.
- **What you say while the agent works reaches it at once.** A question such as "Is it working?" asked during a long command could sit queued for minutes and then get stale answers. Spoken follow-ups now always go into the live run, back-to-back ones go as one message with one answer, and if the agent stays silent on a command the voice says what it is running and for how long.
- **Approvals are said short.** The voice names what it wants to do, such as running git push in a workspace, rather than reading out the whole command line.
- **Restart and install is quiet.** An in-app update no longer shows the installer's scope page, progress bar and Finish page; it installs silently and reopens the app. A first install still shows the installer.

## Fixed

- **Two voices no longer talk over each other.** "One moment." and the answer could play at the same time and cut into each other. Voice mode now plays one line at a time, and drops a "One moment." you haven't heard yet once the real answer is ready.
- **A yes is heard.** "Yes, yes. Oh." and yes or no in Hindi and Punjabi now count as answers to an approval.
- **Talking during an approval doesn't lose it.** Words that aren't a yes or no are held while an approval waits: "what does that do?" is answered from the approval, and the rest goes to the agent once you've answered. Saying it again sends it and cancels the approval.
- **The agent no longer claims app actions it didn't take.** Part of the voice instructions was being cut for space, so the agent could say a new session had started, or agree to keep quiet, without doing it. Those instructions are now never cut.
- **Written answers are no longer read aloud by mistake.** A spoken part the agent didn't close made the whole written answer get read out and hidden on screen. A blank line now ends it, and a piece with no letters or digits, like an ellipsis, is never said.
- **"Wait" and "shut up" don't get a "One moment."** in reply.
