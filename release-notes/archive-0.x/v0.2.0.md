# Vyotiq v0.2.0

Tag: v0.2.0
Published: 2026-09-20T13:34:09Z

---

Second release of the 0.x line. Teammates get a real surface, runs waste far less time, and MCP servers that were reachable all along now connect.

## Added

- **A Teammates view.** The roster, each teammate's task inbox, per-workspace behaviour overrides and the model pin now have a place of their own rather than living in the sidebar. A finished task can be retried; the retry is a new record, so the attempt that failed stays in your history instead of being overwritten by the one that replaced it.
- **Run feedback.** Messages can be rated in place, and each workspace remembers how its runs actually went. Per-run receipts are overwritten and pruned with their session, so they can never show you a recurring problem — this can.
- **A verification gate.** The agent now tracks, while a turn is still running, whether a check actually ran *and* reported clean after the last file it changed. A turn that edited code without verifying it gets caught while it can still do something about it.

## Improved

- **Runs spend less time doing nothing.** Three specific wastes, all measured rather than guessed at:
  - Publishing a plan no longer demotes an Agent-mode run to Plan mode. The plan was already finished, and every run in the telemetry switched straight back — most of them spending a whole model step to do it.
  - Tool-result trimming now only happens under real context pressure. Before, a run could trim a file's contents and then spend hours re-reading the same file.
  - Thinking effort adapts as a run goes: it holds your ceiling through short navigation, eases off only after a sustained read-only stretch, and retries an empty turn at a lower effort before recovering.
- **MCP servers that publish several addresses now connect.** Each candidate address only got 250ms, which is shorter than the real round trip to much of the internet — so every attempt was abandoned shortly before it would have succeeded, and the server looked permanently down. Servers publishing a single address were never affected, which is why this read like an outage somewhere else.
- **Connection failures say what went wrong.** Instead of a raw timeout naming six IP addresses and no hostname, a failed connect now explains itself and offers the action that matches it — Sign in, Retry, or Install.
- **Plugin-bundled MCP servers can be credentialed.** A server nested inside a plugin lost its auth, inputs and setup URL on the way in, so the connect wizard had no sign-in step to show. It now reads the same manifest as a standalone server.
- **One brand, everywhere.** The installed app was drawing its icon from a different kit than the website, at a different size — so the app you installed carried a visibly different mark from the page you got it from. Both now come from the same source, and macOS gets a properly inset icon rather than a squared-off one.

## Removed

- Six bundled skills — **code-review**, **commit-message**, **debug**, **pr-description**, **security-review** and **test-writing** — along with their icons. The bundled catalog now ships 54 packages.

## Fixed

- Running a packaged build and a development build against the same data directory no longer makes them overwrite each other's bundled resources on every launch.
