# Vyotiq v0.3.0

Tag: v0.3.0
Published: 2026-09-20T19:41:09Z

---

Agent V gets a presence outside its own window, and a single quiet place where updates live. Signing in to GitHub stops asking for a code when your machine already has one, and the sidebar stops painting its own buttons over your chat names.

## Added

- **Agent V now sits in the system tray.** The brand mark appears in the tray — the menu bar on macOS — and animates while runs are working, so you can tell whether anything is still going without bringing the window back. Clicking it reopens Agent V, hovering says how many runs are active, and its menu offers Show and Quit.
- **Updates have one home, in the sidebar.** A new version arrives as an entry beside Notifications. It opens its panel once so you cannot miss it, then stays put until you act — there is no dismissing it into silence. The release notes stay on screen through every stage, so what is changing is in view while you decide whether to take it, and nothing is downloaded until you press Download.
- **Every chat in the sidebar has a menu.** Right-click a chat, or use the button on the row, for Rename, Fork chat, Export as Markdown, Copy link and Delete. These were previously a strip of five icons that appeared on hover and competed with the chat name for room.
- **The working indicator is the Agent V mark.** Loading a chat, waiting on GitHub, opening a repository and reading files all showed a generic spinner; they now show the brand mark, animated. It pulses rather than rotates, which keeps it square to the pixel grid and legible at the small sizes it appears at.

## Improved

- **GitHub sign-in uses the sign-in you already have.** If the GitHub CLI on your machine is signed in, Connect GitHub adopts it and finishes on the spot — no browser, no device code to copy. It is also what lets the GitHub MCP server be credentialed at all: that server reads Agent V's own storage, and a token living only in the CLI never reached it.
- **Turning automatic update checks off stops them at once.** The switch only took effect at the next launch, so the app carried on checking for the rest of the session. Off now means no background network calls at all. The Check button still works — an explicit request is always honoured.
- **Checking for updates a second time actually checks again.** Once one update had been found, the button kept handing back that same answer, so a release that landed afterwards stayed invisible until the app was restarted.
- **A failed background check no longer buries a real update.** A scheduled check that happened to run while you were offline would replace "a new version is available" with "Update check failed". Background checks are quiet now and leave the state they found; only a check you asked for reports its errors.
- **Settings reports update state without duplicating the controls.** Settings — About still says what is happening and still has a Check button, but downloading and installing now happen in exactly one place, the sidebar panel, rather than across two surfaces that could disagree with each other. The website, docs and source links moved inline under the app name instead of taking three full-width rows of their own.
- **Connecting an MCP server shows what you are about to agree to.** The sign-in method, whether the credential covers every workspace, and Google access were folded away behind an Options link — so people pressed "Sign in with GitHub" without being shown that there were three ways to do it, or that the default needed no setup at all. Those choices are on screen now.
- **Sidebar chat names use the width they have.** The hover buttons occupied the layout even while invisible, so names were cut short early by the width of a button strip that was not on screen. The buttons now float above the row, and room is held open for them only while they are showing.
- **Custom CSS is the last word over the active skin.** Skin palettes are written with more specificity than a custom :root block, so an overlay colour was quietly ignored no matter where it was placed. It now applies as documented, and the relative order inside your own CSS is untouched.
- **Native is the skin Agent V ships with.** Installs still carrying the previous default are moved across once on launch. A skin you chose yourself is left exactly as it is.

## Removed

- **Update toasts and the floating update card.** Both are replaced by the sidebar entry. The card could be dismissed, and dismissing it is what used to leave people sitting on an old version with nothing left to remind them.

## Fixed

- **Connect GitHub no longer waits for a code that will never arrive.** When the app noticed mid-flow that the CLI had signed in, it abandoned the device wait and kept nothing — a browser had opened, the code went stale, and the dialog sat waiting for a token that was not coming. It now takes that sign-in and completes, and any flow that ends without a token says so rather than hanging.
- **Pressing Download twice starts one download.** A second press could begin a second transfer on top of the first.
- **What's New shows the notes for the version you are actually running.** Dismissing the old update card recorded the *available* version in the same place that tracks the version you last saw, so the two disagreed and the window could stay shut after an update. Installs carrying a value from that are repaired on the next launch, and you are not asked again about a version you already turned down.

## Known issues

- Windows and macOS builds are unsigned. Windows SmartScreen warns on first run, and macOS Gatekeeper refuses a double-click — open it from the right-click menu once to get past that.
- Crash reports are not sent from this build. Crashes are still recorded on your own machine, but the reporting key was absent when it was packaged, so nothing is transmitted anywhere.
