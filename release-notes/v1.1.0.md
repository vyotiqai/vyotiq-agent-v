Agent V 1.1.0 is about whether the agent's work actually holds. A task that changed code now has to show a real check passed before it calls itself done, and the record, the receipt and Home all agree on what counts as one. Extensions is smaller: the skills that duplicated what the agent already does on its own are gone.

## Added

- **The agent checks its own work before it stops.** In Agent mode, a turn that changed code with no passing test, typecheck or lint since the last edit gets one more turn, asking the agent to run a check or say plainly what it left unverified. It asks once per run, and helper instances are held to it too.
- **A folder can be mentioned.** Pick a folder in the @ menu and the agent is given its listing, up to 40 entries with sub-folders marked, and told when the list was cut short.
- **The @ menu lists files as soon as you type @,** instead of showing only recent files until you type a letter.

## Improved

- **Only a real check counts as one.** A command used to count as verification if it exited cleanly, whatever it was; in recorded runs, 143 of 1,679 such commands were actually tests, typechecks or lints. Now only those count, whether the agent ran them as a test or in the terminal. A test run that failed counts as a failure, a lint that exits on a warning counts as a failure, and a check whose output was cut off proves nothing.
- **A check goes stale when anything changes the files after it.** Writes from the terminal, from an MCP tool, from applying a patch or from a merge now all count, not only the agent's own edits. Editing the task's plan or its done-when list does not.
- **The plan panel says why a task is unverified:** the last check failed, no check ran after the files changed, or files changed after the last check passed.
- **Diagnostics works on more projects.** A root tsconfig that only lists project references used to check zero files and report clean; it is now built as a whole. A check that timed out on Windows left its processes running and hung the step, and now stops them all.
- **Changes made by applying a patch show up in Changes and can be undone,** like any other edit. A helper instance limited to some folders can no longer patch files outside them, and can now run diagnostics, which it was refused 22 times in recorded runs.
- **An edit card shows the real line numbers** of the file, not a count starting at 1.
- **The @ and / menus fit the composer.** They follow its width, show how many results matched, and say when a search failed instead of showing an empty list that looks like no matches.
- **Diagrams follow your skin.** Mermaid diagrams used the default colours whatever skin you chose.
- **Menu rows show the focus ring** when you move through them with the keyboard.
- **Home opens faster,** and a run still in progress, or one that changed nothing, is no longer counted as unverified.
- **Run approvals are consistent.** With approvals off, asking to run a command that is not a check as a test now asks you first, the same as running it in the terminal.

## Removed

- **Thirty-nine skills are gone from Extensions.** The twenty-six vendored from Matt Pocock's Skills for Real Engineers, and thirteen of our own: implement-feature, fix-bug, review-code, write-tests, explain-code, create-skill, goal, frontend-design, accessibility, api-design, persona-builder, refactor and analyze-api. A skill you already installed stays installed and keeps working; it just no longer receives updates. To write a new skill, the /create-skill command is still there.
- **The harness review and apply commands.** They drafted and applied changes to the agent's own system prompt from past runs, and only worked inside the Agent V repository itself. Run ratings are kept.

## Fixed

- **Undo no longer loses its history when its index file is damaged.** The index is rebuilt from the saved checkpoints and the damaged copy kept aside; before, every earlier undo point silently disappeared.
- **Undo after a crash no longer overwrites a file it cannot prove is untouched.** If the app stopped mid-turn, a file changed since the agent's write is left alone.
- **A tool that failed no longer threw away the results of the tools that ran beside it** in the same step.
- **A run can no longer loop forever.** A run stops after 500 steps with a notice, and a model that repeats the same tool call in one reply is cut off the way a flood of calls already was; one run spent 33 minutes that way.
- **A run that ended on an error resumes with the right step count,** rather than carrying the old one forward.
- **Older runs reappear on Home and in usage.** Receipts written by earlier builds were skipped once the receipt format moved on.
- **A run's receipt lists every file it wrote,** across every time it was resumed, not only the last.
- **The line counts in Changes match the list** for large rewrites, and a removed line that starts with two dashes is no longer dropped from an edit card.
- **Waiting on a helper instance after a restart** no longer polls its status twice a second, and no longer leaks memory while it waits.

## Known issues

- Windows and macOS builds are unsigned. Windows SmartScreen warns on first run, and macOS Gatekeeper refuses a double-click — open it from the right-click menu once.
- Crash reports are not sent from this build. Crashes are recorded on your own machine only.
