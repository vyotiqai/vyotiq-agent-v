# profiles

Tiny helpers for showing people.

- `getDisplayName(user)` (src/displayName.js) — the name to show: the nickname when
  set, otherwise "First Last", otherwise the email's local part.
- `greet(user)` (src/greeting.js) — "Hello, <name>!".
- `profileCard(user)` (src/profile.js) — a one-line card.
